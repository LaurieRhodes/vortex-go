# vortex-go

A native Go implementation of the [Vortex columnar file format](https://vortex.dev/).

Vortex is a next-generation columnar file format (Linux Foundation project) that achieves 100x faster random access, 10-20x faster scans, and 5x faster writes compared to Apache Parquet, with similar compression ratios.

`vortex-go` reads and writes Vortex files from pure Go — no CGo, no Rust FFI.

## Status

**Early development.** File reader in progress.

## Design

The Vortex file format uses:
- **FlatBuffers** for file structure (footer, layout tree, schema, array descriptors)
- **Protobuf** for encoding metadata and scalar statistics
- **Published algorithms** for compression (FastLanes, FSST, ALP, BtrBlocks)

All of these have mature Go libraries, making a native Go implementation practical.

See `docs/` for the full project specification and encoding roadmap.

## Project Structure

```
schemas/
  flatbuffers/    # .fbs schemas copied from vortex reference (code generation source)
  proto/          # .proto schemas copied from vortex reference
internal/
  flatbuf/        # Generated FlatBuffer Go code
  proto/          # Generated Protobuf Go code
layout/           # Layout tree types (Struct, Chunked, Zoned, Flat, Dictionary)
encoding/         # Array encoding decoders/encoders
writer/           # Vortex file writer
cmd/vtxinfo/      # CLI tool for inspecting Vortex files
testdata/         # Reference files generated by Rust vx CLI
```

## Building

```bash
# Generate FlatBuffer code (requires flatc)
flatc --go -o internal/flatbuf schemas/flatbuffers/footer.fbs

# Generate Protobuf code (requires protoc + protoc-gen-go)
protoc --go_out=internal/proto --go_opt=paths=source_relative schemas/proto/*.proto

# Build
go build ./...

# Test
go test ./...
```
